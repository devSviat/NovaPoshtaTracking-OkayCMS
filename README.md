# Модуль NovaPoshtaTracking для OkayCMS

Модуль дозволяє створювати та відстежувати експрес-накладні (ТТН) Нової Пошти безпосередньо з адмін-панелі магазину.  
Автоматично оновлює статуси накладних та дозволяє фільтрувати замовлення за статусом доставки.

## Можливості

- Створення експрес-накладних (ТТН) через API Нової Пошти: на відділення, у поштомат і на адресу.  
- Адресна ТТН створюється з адресою з довідника Нової Пошти (місто, вулиця, будинок, квартира, коментар), тож у редакторі кабінету НП поля адреси заповнені. Якщо вулиці немає в довіднику, ТТН створюється з адресою текстом, а менеджер бачить попередження.  
- Тип доставки ТТН береться зі способу доставки замовлення; суперечливі дані (і адреса, і відділення) зупиняють створення до запиту в НП з поясненням, що виправити.  
- Привʼязування накладної, виписаної вручну на сайті Нової Пошти, за її номером.  
- Відстеження статусів накладних в реальному часі.  
- Автоматичне оновлення статусів накладних через cron (кожні 10 хвилин).  
- Фільтрація замовлень за статусом Нової Пошти в списку замовлень.  
- Збереження додаткової інформації про доставку (габарити, вага, тип вантажу тощо).

## Вимоги

- PHP 8.5+
- OkayCMS 4.5.3 (чиста або [форк](https://github.com/devSviat/OkayCMS-Fork))
- Перевірено на PHP 8.5 — на чистій OkayCMS 4.5.3 і на [форку](https://github.com/devSviat/OkayCMS-Fork):
  створення ТТН на відділення, у поштомат, на адресу, з накладеним платежем і масове створення.
  На нижчих версіях PHP модуль не перевірявся.
- API-ключ Нової Пошти  
- Модуль NovaposhtaCost (для роботи з даними доставки)

## Встановлення

### Варіант 1: Скачування з GitHub

1. Скачайте останню версію модуля з [останнього релізу на GitHub](https://github.com/devSviat/NovaPoshtaTracking-OkayCMS/releases/latest).  
2. Розпакуйте архів на сервері в каталог: `{OkayCMS_root}/Okay/Modules/`

### Варіант 2: Встановлення через Git

1. Виконайте команду в директорії `{OkayCMS_root}/Okay/Modules/Sviat`:
   ```bash
   git clone https://github.com/devSviat/NovaPoshtaTracking-OkayCMS.git NovaPoshtaTracking
   ```
### Результат встановлення

Шлях до модуля має бути таким:
   ```bash
   {OkayCMS_root}/Okay/Modules/Sviat/NovaPoshtaTracking/
   ```  

## Важливо

**Рекомендується оновити бібліотеку `giggsey/libphonenumber-for-php` до останньої версії.**  
Для деяких телефонних кодів (наприклад, 077) може виникати помилка "User phone is invalid" при створенні накладної, якщо використовується застаріла версія бібліотеки. Для оновлення виконайте команду:

```bash
composer update giggsey/libphonenumber-for-php
```
